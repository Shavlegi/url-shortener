# Mini Link — ბმულების შემოკლება

Mini Link — უფასო, თვით-ჰოსტინგის ბმულების შემოკლება — **Cloudflare Workers + Cloudflare D1**,
ქართული ინტერფეისით, QR კოდებით და კლიკების სტატისტიკით. ვიზიტორების IP
მისამართები ინახება მხოლოდ ადმინისტრატორის სტატისტიკისთვის (v10.5 — 90 დღე,
მერე ავტომატურად იშლება, გარდა ადმინის ფავორიტებში შენახული IP-ებისა —
v10.7; ქუქი-თრექინგი არ არის).

**საჯარო საიტი:** ნებისმიერს შეუძლია ბმულის დამოკლება `minilink.space`-ზე —
რეგისტრაციის გარეშე. **ადმინ პანელი** ცალკე მისამართზეა
(`admin.minilink.space`, ან `*.workers.dev`) — იქ ადმინი ხედავს ყველა ბმულს
და შლის საეჭვოს.

**v2 — მომხმარებლის ანგარიშები (ნებაყოფლობითი):** ვისაც უნდა, რეგისტრირდება
(username + მეილი + პაროლი), მეილზე 6-ნიშნა კოდით ადასტურებს ანგარიშს და
თავის ბმულებს საკუთარ სივრცეში („ჩემი ბმულები") ინახავს. ანონიმური დამოკლება
ისევ მუშაობს — რეგისტრაცია სავალდებულო არ არის. ადმინი ხედავს, ვინ რა ბმული
დაამოკლა, და მართავს მომხმარებლებს (გათიშვა/წაშლა).

> **English summary:** Mini Link — a free, self-hosted URL shortener on Cloudflare Workers + D1,
> with a Georgian UI, QR codes and click stats. Visitor IPs and visit details
> (country/city/ISP, device, language, referrer) are logged admin-only
> with 90-day retention (v10.0/v10.5; admin-saved favorite IPs exempt,
> v10.7); no cookie tracking.
> The public site (minilink.space) lets anyone shorten a link; the admin panel
> (admin.minilink.space) is separate and password-protected. Admin login uses
> PBKDF2-SHA256 + server-side sessions. v2 adds voluntary user accounts with
> email verification (Resend), per-user link spaces, and admin user management.
> See SECURITY.md for the threat model and known limitations.

## შესაძლებლობები

- **საჯარო დამოკლება** — ნებისმიერი ვიზიტორი ამოკლებს ბმულს `minilink.space`-ზე,
  რეგისტრაციის გარეშე (ავტომატური 6-სიმბოლოიანი სახელი; ლიმიტი: 3/წუთი + 10/საათი ერთ IP-ზე)
- **v2 — მომხმარებლის ანგარიშები (ნებაყოფლობითი):** რეგისტრაცია username + მეილი + პაროლი;
  მეილის ვერიფიკაცია 6-ნიშნა კოდით (10 წუთი, 5 მცდელობა); პაროლის აღდგენა მეილზე კოდით;
  საკუთარი სივრცე „ჩემი ბმულები" (მხოლოდ თავისი ბმულები: კოპირება, QR, ჩართვა/გამორთვა, წაშლა);
  ადმინიდან ჩანს თითოეული ბმულის მფლობელი (username ან „ანონიმური") და მომხმარებლების
  მართვა (გათიშვა/ჩართვა, წაშლა — წაშლილი მომხმარებლის ბმულები ანონიმური ხდება

## დაყენება — ნაბიჯ-ნაბიჯ

### 1. GitHub რეპოზიტორია

1. შექმენით ცარიელი **public** რეპო, სახელი: `url-shortener`
   (`https://github.com/new` — README/LICENSE/.gitignore არ მონიშნოთ).
2. ატვირთეთ ამ პროექტის ფაილები (ბრაუზერით ან `git push`-ით).
3. **არასოდეს** ატვირთოთ რეალური პაროლები, ჰეშები ან secret-ები.

### 2. Cloudflare ანგარიში

1. შექმენით უფასო ანგარიში: https://dash.cloudflare.com/sign-up
   (იმეილი + პაროლი, მეილის დადასტურება).
2. ბარათი არ გჭირდებათ — უფასო ტარიფისთვის არაფერს ითხოვს.

### 3. D1 ბაზის შექმნა (ტერმინალიდან — wrangler)

```bash
npm install
npx wrangler d1 create mini-link-db
```

ბრძანება დაბეჭდავს `database_id`-ს — ჩასვით `wrangler.toml`-ში
(`REPLACE_WITH_YOUR_D1_DATABASE_ID`-ის ნაცვლად) და დააკომიტეთ.

მერე მიგრაციის გაშვება:

```bash
npx wrangler d1 migrations apply mini-link-db --remote
```

> დეშბორდიდან (ტერმინალის გარეშე): Cloudflare dashboard → **Workers & Pages** →
> **D1** → **Create database** (სახელი: `mini-link-db`) → გახსენით ბაზა →
> **Console** ჩანართში ჩასვით `migrations/0001_init.sql`-ის შიგთავსი და გაუშვით.

### 4. ადმინის პაროლის ჰეში

1. გახსენით `scripts/make-hash.html` ბრაუზერში (ფაილი თქვენს კომპიუტერში/ტელეფონში).
2. ჩაწერეთ ძლიერი პაროლი (მინ. 12 სიმბოლო) და დააჭირეთ „ჰეშის შექმნა".
3. დაკოპირებული ჰეში (`pbkdf2$100000$...`) **არ შეინახოთ არსად** — პირდაპირ
   ჩასვით Cloudflare secret-ად (შემდეგი ნაბიჯი). პაროლი თავად დაიმახსოვრეთ.

### 5. Secrets (Cloudflare)

ტერმინალიდან:

```bash
npx wrangler secret put ADMIN_PASSWORD_HASH   # ჩასვით ჰეში მე-4 ნაბიჯიდან
npx wrangler secret put SESSION_SECRET        # გრძელი შემთხვევითი სტრიქონი, მინ. 32 სიმბოლო
npx wrangler secret put RESEND_API_KEY        # v2 (არასავალდებულო): Resend API გასაღები
                                              # მეილის ვერიფიკაციისთვის — იხ. „მეილის
                                              # გაგზავნა (v2)" ქვემოთ
```

> დეშბორდიდან: Worker → **Settings** → **Variables** → **Add variable** →
> ტიპი **Secret** → სახელი + მნიშვნელობა → **Save**.

`SESSION_SECRET`-ის გენერირება (თუ კომპიუტერი გაქვთ):

```bash
openssl rand -hex 32
```

5. ადმინი მომხმარებლის პროფილის მოდალში ლიმიტს 8-მდე ზრდის → მე-6/მე-7
   ღილაკი ემატება; პროფილის გარეშე მომხმარებელზე 404 `profile_not_found`.
6. ფოტო: 2 MB-ზე დიდი უარყოფილია; შეცვლა ძველ R2 ობიექტს შლის;
   მოხსნის შემდეგ ინიციალები ჩანს. `/@username/avatar` სურათს აბრუნებს.
7. XSS: სახელი/ბიო/სათაური `<script>`-ით — გვერდის წყაროში გაქცეულია,
   სკრიპტი არ გაეშვება. `show_views` გათიშვისას მრიცხველი გვერდზე
   არ ჩანს, რედაქტორში კი ჩანს. `/@NIKA` (დიდი ასოებით) იმავე
   პროფილს ხსნის.
8. რედაქტორი: ↑/↓ გადალაგება, რედაქტირება, წაშლა მუშაობს; სხვისი
   ღილაკის id-ით reorder 400-ს აბრუნებს.

## პაროლის შეცვლა / აღდგენა (თუ დაგავიწყდათ)

პაროლის აღდგენის მეილი **არ არსებობს** — ასეა ჩაფიქრებული (უსაფრთხოება).
შეცვლა (იგივე ნაბიჯები აღდგენისთვისაც):

1. გახსენით `scripts/make-hash.html`, შექმენით ახალი პაროლის ჰეში.
2. Cloudflare dashboard → Worker → **Settings → Variables** → `ADMIN_PASSWORD_HASH`
   secret-ის მნიშვნელობა ახლით ჩაანაცვლეთ → **Save** → **Redeploy** (თუ საჭიროა).
3. შედით ახალი პაროლით.
4. დეშბორდში დააჭირეთ **„ყველა მოწყობილობიდან გამოსვლა"** — ყველა ძველი
   სესია დაიხურება (პაროლის შეცვლა თავისით სესიებს არ ხურავს).

## ბექაფი

- **ექსპორტი:** დეშბორდში ღილაკი „ექსპორტი (JSON)" — ჩამოტვირთავს ყველა ბმულს.
- **იმპორტი:** ღილაკი „იმპორტი (JSON)" — აღადგენს ფაილიდან (არსებული სახელები
  გამოტოვება, დუბლიკატები არ იქმნება).
- შეინახეთ ბექაფი უსაფრთხო ადგილას (მაგ. თქვენს ტელეფონში/Drive-ში).

## ბრენდი და დომენი

- **სახელი: Mini Link** — სათაური `public/index.html`-შია; ფერები
  `public/styles.css`-ის `:root` ცვლადებია. შეცვალეთ და ხელახლა დადეპლოით.
- **დომენები:**
  - **minilink.space** (ნაყიდია) — **საჯარო საიტი**: დამოკლების ფორმა, პაროლის გარეშე.
    Cloudflare dashboard → Worker → **Settings → Custom Domains** → **Add Custom Domain** → `minilink.space`.
  - **admin.minilink.space** — **ადმინ პანელი**: შესვლა + დეშბორდი. იმავე ადგილას
    ემატება მეორე Custom Domain-ად (უფასო ქვედომენი, იმავე ზონაში).
  - **`*.workers.dev`** მისამართიც ადმინ პანელს ხსნის (სარეზერვო შესასვლელი).
  - მოკლე ბმულები ყოველთვის `minilink.space/...` სახით იქმნება — იმ შემთხვევაშიც კი,
    როცა ადმინი ქმნის მათ ადმინ პანელიდან (კოდში `CONFIG.publicHost`).
- მოკლე სახელის ფორმატი (6 სიმბოლო) `src/index.js`-ის `CONFIG`-ში იცვლება.
  საჯარო ფორმის ლიმიტები (`publicCreateMaxPerMin` / `publicCreateMaxPerHour`)
  იქვეა.
